Brushline — politique de confidentialité

Dernière mise à jour : 17 octobre 2026. Éditeur : sogerg enterprise — contact : sogerg.enterprise@gmail.com.

Seul l’arrêté préfectoral ou municipal fait foi. Brushline produit un tracé indicatif ; ce n’est ni un avis juridique ni un document officiel.

En bref

Pas de compte, pas de publicité, pas de mesure d’audience. Vos propriétés, parcelles, bâtiments dessinés, voisins, dates et photos restent sur votre téléphone.

Ce qui est enregistré sur le téléphone

  • Les propriétés, le tracé calculé, l’état de chaque voisin et les dates : dans une base locale de l’app (chiffrée dans la version publiée ; la clé est gardée dans le trousseau sécurisé du téléphone).
  • Les photos avant / après : copiées dans le dossier privé de l’app, avec leur date et, si vous l’activez, la position et la direction.
  • La langue choisie et les réglages des rappels.

« Effacer toutes mes données », dans les réglages, supprime tout cela. Désinstaller l’app aussi.

Ce qui passe par le réseau

  • Paquets de commune (cadastre et zonage, données publiques ouvertes) : quand le service est en ligne, l’app télécharge la liste des communes et le paquet de la commune choisie. Le serveur voit donc quelle commune est demandée et l’adresse IP de la connexion, comme tout site web ; il ne reçoit ni votre adresse, ni vos parcelles, ni vos photos.
  • Danger de feu du jour : l’app télécharge le fichier du jour de votre pays ; il contient les niveaux de tous les départements et ne dépend pas de vous.
  • Ces fichiers sont servis par Cloudflare (hébergeur). L’éditeur ne conserve aucun journal personnel.
  • Les liens vers les textes officiels s’ouvrent dans votre navigateur.
  • Les modèles de lettre et le dossier PDF sont créés sur le téléphone ; c’est vous qui choisissez de les partager.

Cette version n’envoie aucune notification depuis un serveur : les rappels sont programmés sur le téléphone.

Autorisations

  • Appareil photo et photos : prendre ou choisir les photos avant / après.
  • Position (pendant l’utilisation seulement, facultative) : centrer le plan sur votre maison et noter où une photo a été prise. Elle n’est jamais envoyée.
  • Boussole : noter la direction d’une photo.
  • Notifications : rappels d’échéance programmés sur le téléphone.

Avis sur l’app

L’app peut afficher la fenêtre d’avis du système (App Store ou Google Play) ; cette fenêtre est gérée par Apple ou Google.

Sources des données

Cadastre : DGFiP / Etalab, Licence Ouverte 2.0. Zonage débroussaillement : IGN, Licence Ouverte 2.0. Danger de feu : Météo-France (Météo des forêts), Licence Ouverte 2.0.

Enfants

L’app s’adresse aux propriétaires et n’est pas destinée aux enfants.

Vos droits

L’éditeur ne détient aucune donnée personnelle vous concernant. Pour toute question : sogerg.enterprise@gmail.com.
